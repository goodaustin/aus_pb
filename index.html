今日三件事
1
美系 CSP capex 與 AI ASIC 兩條線今天合流，2027 不是只有 GPU，而是 custom silicon / rack power / thermal / optical / substrate 全部一起吃 capacity allocation：KGI 電子硬體報告把五大美系 CSP 2026E capex 上修到 US$795.1bn、YoY +77%，2027E 再到 US$1.061tn、YoY +33%；今天新增 GS 緯穎、MS 創意、五家聯發科報告，把同一個故事補齊：CSP 不是只多買 GPU，而是 TPU / ASIC / general server / power shelf / InP optical / ABF substrate 同步升規格。
2
聯發科 2454 的券商共識明顯升級：2027 AI ASIC revenue anchor 從 US$7-12bn 往 US$12-16bn 移，分歧只剩誰敢把 2028 想更大：GS TP NT$7,000、Citi TP NT$6,800、MS TP NT$5,588、BofA PO NT$5,230、Daiwa 升評 Buy TP NT$4,088。共同點是 2026 AI ASIC >US$2bn、2027 SAM US$80bn、share target 15-20%；分歧在 2028，GS 估 AI ASIC US$52.5bn、BofA 估 cloud ASIC US$45.8bn，Daiwa 則保守到 US$22bn。這是今天最需要拆假設的地方。
3
硬體 bottleneck basket 變厚：緯穎上修到 NT$10,000、全新買 MOCVD、景碩 ABF mix 改善，元太則靠 Vusion read-through 等待 2H26 數據驗證：GS 緯穎 TP NT$10,000，2026-28 revenue CAGR 32%，AI server SKU 與 general server 同時推；GS 全新 MOCVD 訂單 NT$653mn，指向 InP epiwafer 2027 後需求；GS 景碩 2Q26 EPS beat 10-14%，ABF mix 拉毛利；MS 元太維持 OW TP NT$250，但重點是 Vusion Walmart / Carrefour / Mexico / JYSK 等 ESL roll-out 能不能讓元太 2H26 revenue 補上 1H26 只 +1% YoY 的落差。

利多

重要更新
2Q26 本業只是符合預期。Revenue NT$152.183bn，QoQ +2%、YoY +1%，比財測區間上緣高 2%；GPM 46.2%、OPM 15.0% 符合 KGI；EPS NT$15.28，比 KGI / consensus 高 5% / 8%，但主要來自業外收益優於預期。2Q26 結果與 3Q26 guide：2Q26 revenue NT$152.2bn，QoQ +2%、YoY 約 flat；GPM 46.2%，OPM 15.0%，EPS 約 NT$15.28。 〔pb〕
